# K-EXAONE 2.5 vs OpenRouter 무료 주간 사용량 상위 모델

## 결론

2026-11-10 실제 API로 완료한 **6인 경기 3회**에서 세 모델의 팀 승률은 모두
**16.7% (1승 / 플레이어 출전 6회)**였다. 세 경기 모두 마피아가 승리했다.
각 모델이 마피아를 맡은 1회는 승리하고 시민 진영에 배정된 5회는 패배했다.
이 결과는 **모델 성능이 동등하다는 증거가 아니라, 이 작은 표본으로 차이를
구분하지 못했다는 뜻**이다.

## 비교 모델 선정 근거

확인 시각: **2026-11-10 02:23 UTC**.
OpenRouter의 [무료 가격 필터 + Top Weekly 정렬](https://openrouter.ai/models?max_price=0&order=top-weekly)을
브라우저에서 확인했다. 사용량은 페이지의 “Tokens processed in the last 7 days”
기준이며, 요청 수나 사용자 수가 아니다. 표의 사용량은 화면에 표시된 반올림 값이다.

| 무료 주간 순위 | 모델 | API model ID | 최근 7일 토큰 |
|---|---|---|---:|
| 비교 대상 | K-EXAONE 2.5 | `k-exaone_v2.5` | OpenRouter 순위 대상 아님 |
| 1 | NVIDIA Nemotron 3 Ultra | `nvidia/nemotron-3-ultra-550b-a55b:free` | 3.21T |
| 2 | NVIDIA Nemotron 3.5 Super VL | `nvidia/nemotron-3.5-super-vl:free` | 2.90T |

실행 직전 [OpenRouter 모델 API](https://openrouter.ai/api/v1/models)의 입력/출력
가격이 모두 `0`인지 확인했고, 두 모델의 사전 시험 응답에서도 `usage.cost: 0`을
확인했다. 모델 ID를 고정했으며 `openrouter/free` 라우터나 다른 모델로의 fallback은
사용하지 않았다. 사전 점검에 사용했던 Gemma, Lightning, Flint의 응답은 경기나
승률 집계에 포함되지 않는다.

EXAONE은 [공식 API](https://docs.exaone.ai/en/docs/k-exaone-2.5)를 사용했다.
Pi에 등록된 방식과 동일하게 macOS Keychain의 `pi-exaone-api-key` 항목에서 키를
읽었으며, 키 자체는 저장소나 결과물에 복사하지 않았다.

## 실험 설정

- 설정: [`config.compare.yaml`](../config.compare.yaml)
- 6명: 모델당 2명
- 역할: 마피아 1명, 경찰 1명, 의사 1명, 일반 시민 3명
- 낮 공개 발언: 플레이어당 하루 최대 1회
- runner: `graph`, 최대 5라운드
- seed: 세 경기 모두 `42`
- 모델 그룹을 두 좌석씩 순환하여 각 모델이 모든 좌석/이름을 한 번씩 경험
- 모델별 누적 역할: 마피아 1회, 경찰 1회, 의사 1회, 일반 시민 3회
- API: `max_tokens=4096`(reasoning 포함), timeout 120초, 최대 4회 시도
- EXAONE: `reasoning_effort=low`; OpenRouter: 모델 기본 reasoning 설정
- sampling: 각 제공자의 기본값. seed가 같아도 LLM 응답까지 재현되지는 않음
- 언어: 모든 역할에 한국어 system 지침 적용, 투표 토큰과 플레이어 이름은 원문 유지 지시

### 실제 실행과 중단 처리

최초 명령:

```bash
EXAONE_API_KEY_COMMAND='security find-generic-password -s pi-exaone-api-key -w' \
uv run python -u main.py \
  --config config.compare.yaml --tournament 3 --seed 42 --max-rounds 5
```

1경기 완료 후 2경기 도중 명령 실행기의 **1,800초 wall-clock 제한**에 걸렸다.
완료된 rotation 0은 보존하고, 미완료 경기는 제외했다. 이후 동일 설정으로
rotation 1과 2를 각각 `run_match`로 병렬 실행하여 완료된 세 경기만 합산했다.
후속 두 경기에서는 Ultra 요청이 각각 한 번 120초 read timeout을 일으켰지만
동일 모델 재시도로 성공했다. 다른 모델이나 가짜 응답으로 대체하지 않았다.

최종 JSON의 `execution_note`에 이 복구 과정을 명시했다. 최초 실행은 02:25 UTC,
마지막 경기 완료는 03:11 UTC였다. 무료 endpoint 지연으로 실행 시간이 길었다.

## 모델별 승률

**정의:** 출전한 플레이어가 속한 진영이 이겼으면 승리로 센다. 도중에 탈락해도
진영이 이기면 승리다. 한 모델의 복제 플레이어들이 반대 진영에 있을 수 있으므로
“모델이 등장한 경기 중 어느 한 명이라도 이긴 비율”로 계산하지 않는다.
무승부는 승리로 세지 않고 전체 출전 분모에는 포함한다.

| 모델 | 플레이어 출전 | 승/패/무 | 전체 승률 | 마피아 진영 | 시민 진영(경찰·의사 포함) |
|---|---:|---|---:|---:|---:|
| K-EXAONE 2.5 | 6 | 1 / 5 / 0 | 16.7% | 1/1 (100%) | 0/5 (0%) |
| Nemotron 3 Ultra | 6 | 1 / 5 / 0 | 16.7% | 1/1 (100%) | 0/5 (0%) |
| Nemotron 3.5 Super VL | 6 | 1 / 5 / 0 | 16.7% | 1/1 (100%) | 0/5 (0%) |

역할별 승/출전도 세 모델 모두 동일하다:
마피아 **1/1**, 경찰 **0/1**, 의사 **0/1**, 일반 시민 **0/3**.

## 한국어 및 출력 검증

측정된 자연어 이벤트는 **전체 모델 합계 90개**였다:
전략 26개, 발언 신청 이유 30개, 공개 발언 26개, 마피아 대화 8개.

| 모델 | 자연어 이벤트 | 한글 포함 |
|---|---:|---:|
| K-EXAONE 2.5 | 34 | 34 |
| Nemotron 3 Ultra | 24 | 23 |
| Nemotron 3.5 Super VL | 32 | 32 |
| 합계 | 90 | 89 |

공개 발언 26개는 모두 한글을 포함했다. Ultra가 경기 2의 첫날 Alex 전략을
영어로 출력한 1건이 있었다. 다른 응답에도 이름의 한글 음역이나 영어 단어 혼용이
있었으므로 **한글 포함을 완전한 한국어 준수율로 해석하면 안 된다**.
파싱 대상인 낮 투표 26건, 밤 투표 8건은 모두 유효했다.

**실험 후 보완:** 한글이 없는 자연어 응답은 같은 모델에 같은 판단을 한국어로
다시 작성하도록 한 번 재요청하고, 재차 실패하면 경기를 중단하는 검사를 추가했다.
이름만 출력하는 낮 투표는 예외다. 이 보완은 회귀 테스트로 검증했으며,
위 승률과 대화 통계는 **보완 전 실제 3경기 기록을 그대로 유지한 결과**다.
보완 후 3경기를 다시 측정한 것으로 주장하지 않는다.

## 해석상 한계

1. 3경기·seed 한 묶음뿐이다. 플레이어 출전 6회는 독립 경기 6회가 아니다.
2. 세 모델 모두 마피아일 때만 승리했다. 모델 순위나 통계적 우월성을 주장할 수 없다.
3. 역할/좌석 배정 수는 균등하지만 실제 생존 시간과 발언 횟수는 다르다.
4. 기존 엔진의 경찰 조사·의사 보호 대상은 LLM이 아닌 난수로 선택된다.
   따라서 특수 능력을 포함한 마피아 게임 전반의 실력을 평가하는 실험이 아니다.
5. 역할 추론은 휴리스틱이며, 모델이 이름을 한글로 음역하면 일부 참조를 놓칠 수 있다.
6. reasoning 설정은 제공자 간 완전히 같지 않다. 한국어 검사 보완 전 결과라는
   버전 차이도 있으므로 후속 비교 시 새 버전으로 여러 seed 묶음을 다시 측정해야 한다.
